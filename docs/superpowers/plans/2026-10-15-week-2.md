## Global Constraints

- Units are metres, seconds and radians throughout.
- All randomness goes through generators derived from the one passed into `Simulation`. Never call `np.random.*` module functions or Python's `random`.
- A run is fully determined by `(Config, seed)`; same inputs give an identical result dict.
- RNG seeds come from `(experiment name, cell index, seed index)` via `numpy.random.SeedSequence`. The cell index identifies the environment/parameter configuration, never the controller.
- Every result row records the config hash, git commit, platform and the versions of numpy, scipy, pandas, matplotlib and PyYAML.
- Tuning uses only the experiment names `tune_c2` and `tune_c3`. Never reuse `gate` or `E1`–`E7` for tuning; never tune on main-experiment names.
- Never change a parameter or the model to make a result look better. Report what the code produces.
- No robot–robot collisions.
- Controllers differ only in avoidance, move-blocking (oracle) and marking; search/return behaviour is shared.
- `results/` is git-ignored; never commit CSVs or GIFs.
- Commands run from the repository root in Git Bash; the interpreter is `.venv/Scripts/python`.

```python
def hazard_tangent(world: World, pos: np.ndarray, direction: np.ndarray) -> np.ndarray:
    """Unit vector along the edge of each robot's nearest hazard, on the side closer to `direction`."""
    diff = pos[:, None, :] - world.hazard_xy[None, :, :]
    dist = np.linalg.norm(diff, axis=2)
    rows = np.arange(len(pos))
    nearest = dist.argmin(axis=1)
    radial = diff[rows, nearest] / np.maximum(dist[rows, nearest], 1e-9)[:, None]
    tangent = np.column_stack((-radial[:, 1], radial[:, 0]))
    side = np.sign((tangent * direction).sum(axis=1))
    side[side == 0] = 1.0
    return tangent * side[:, None]
```

```python
        cfg, sw, world = self.cfg, self.swarm, self.world
        kick = self.motion_rng.normal(0.0, 0.5, len(sw.pos))  # one draw per robot, always
        step = cfg.speed * cfg.dt
        new = sw.pos + step * unit(sw.heading)
        hit_wall = ((new < 0) | (new > cfg.arena_size)).any(axis=1)
        new = np.clip(new, 0.0, cfg.arena_size)
        blocked = blocks_move(cfg, world, new)
        if blocked.any():
            # The oracle slides along the hazard edge instead of stepping in.
            slide = np.clip(sw.pos + step * hazard_tangent(world, sw.pos, unit(sw.heading)),
                            0.0, cfg.arena_size)
            slides = blocked & ~in_hazard(world, slide)
            new[slides] = slide[slides]
            blocked = blocked & ~slides
        moves = alive & ~blocked
        sw.pos[moves] = new[moves]
        bounce = alive & (hit_wall | blocked)
        sw.heading[bounce] += np.pi + kick[bounce]
```

```python
"""Where a result came from: code version, machine and package versions (spec section 6).

Exact re-runs are only claimed on the same machine and environment: chaotic
dynamics can amplify last-bit floating-point differences between CPUs.
"""

from __future__ import annotations

import platform
import subprocess
from importlib.metadata import version
from pathlib import Path

PACKAGES = {"numpy": "numpy", "scipy": "scipy", "pandas": "pandas",
            "matplotlib": "matplotlib", "pyyaml": "PyYAML"}


def git_commit(root: Path) -> str:
    try:
        sha = subprocess.run(["git", "rev-parse", "--short", "HEAD"], cwd=root,
                             capture_output=True, text=True, check=True).stdout.strip()
        dirty = subprocess.run(["git", "status", "--porcelain"], cwd=root,
                               capture_output=True, text=True, check=True).stdout.strip()
        return sha + ("-dirty" if dirty else "")
    except (OSError, subprocess.CalledProcessError):
        return "unknown"


def provenance(root: Path) -> dict:
    info = {
        "git_commit": git_commit(root),
        "python": platform.python_version(),
        "platform": platform.platform(),
        "machine": platform.machine(),
        "processor": platform.processor(),
    }
    info.update({f"v_{key}": version(dist) for key, dist in PACKAGES.items()})
    return info
```

- [ ] **Step 4: Implement `src/swarmhazard/experiment.py`**

```python
"""Experiment files: which configurations, controllers and seeds to run.

A cell is one configuration (a set of parameter overrides). Every controller
runs every seed in every cell, and the RNG depends on (name, cell, seed) only,
so controllers are compared on identical conditions.
"""

from __future__ import annotations

import time
from itertools import product
from pathlib import Path

import yaml

from swarmhazard.config import config_hash, load_config
from swarmhazard.seeding import make_rng
from swarmhazard.sim import run


def load_experiment(path: Path, root: Path) -> dict:
    spec = yaml.safe_load(Path(path).read_text())
    shared = {}
    if spec.get("overrides_file"):
        shared.update(yaml.safe_load((root / spec["overrides_file"]).read_text()) or {})
    shared.update(spec.get("overrides") or {})
    spec["overrides"] = shared
    return spec


def build_cells(spec: dict) -> list[dict]:
    if spec.get("grid"):
        names = list(spec["grid"])
        return [dict(zip(names, values)) for values in product(*(spec["grid"][n] for n in names))]
    return [dict(cell) for cell in (spec.get("cells") or [{}])]


def build_jobs(spec: dict, seeds: int | None = None, n_steps: int | None = None) -> list[dict]:
    shared = dict(spec.get("overrides") or {})
    if n_steps is not None:
        shared["n_steps"] = n_steps
    n_seeds = seeds if seeds is not None else spec["seeds"]
    return [
        {"experiment": spec["name"], "base": spec["base"], "overrides": {**shared, **cell},
         "params": cell, "controller": controller, "cell": index, "seed": seed}
        for index, cell in enumerate(build_cells(spec))
        for controller in spec["controllers"]
        for seed in range(n_seeds)
    ]


def run_one(job: dict, root: Path) -> dict:
    cfg = load_config(root / job["base"], **job["overrides"], controller=job["controller"])
    rng = make_rng(job["experiment"], job["cell"], job["seed"])
    start = time.perf_counter()
    row = run(cfg, rng)
    row.update(
        experiment=job["experiment"],
        cell=job["cell"],
        controller=job["controller"],
        seed=job["seed"],
        config_hash=config_hash(cfg),
        wall_s=round(time.perf_counter() - start, 3),
    )
    row.update({f"p_{name}": value for name, value in job["params"].items()})
    return row
```

```python
from functools import partial
from pathlib import Path

import pandas as pd

from swarmhazard.experiment import build_jobs, load_experiment, run_one
from swarmhazard.provenance import provenance

def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("experiment", type=Path)
    parser.add_argument("--seeds", type=int, help="override the number of seeds (smoke tests)")
    parser.add_argument("--n-steps", type=int, help="override episode length (smoke tests)")
    parser.add_argument("--workers", type=int, default=None, help="parallel processes (default: all cores)")
    parser.add_argument("--allow-dirty", action="store_true", help="run despite uncommitted changes")
    args = parser.parse_args()

    spec = load_experiment(args.experiment, ROOT)
    smoke = args.seeds is not None or args.n_steps is not None
    info = provenance(ROOT)  # recorded before running, so edits during the run cannot mislabel rows
    if info["git_commit"].endswith("-dirty") and not (smoke or args.allow_dirty):
        sys.exit("Refusing to run: uncommitted changes. Commit first, or pass --allow-dirty.")

    jobs = build_jobs(spec, seeds=args.seeds, n_steps=args.n_steps)
    start = time.perf_counter()
    with ProcessPoolExecutor(max_workers=args.workers) as pool:
        rows = list(pool.map(partial(run_one, root=ROOT), jobs, chunksize=4))

    df = pd.DataFrame(rows)
    for key, value in info.items():
        df[key] = value
    out = ROOT / "results" / f"{spec['name']}{'_smoke' if smoke else ''}.csv"
    out.parent.mkdir(exist_ok=True)
    df.to_csv(out, index=False)

    print(f"{len(df)} runs in {time.perf_counter() - start:.1f} s -> {out}")
    print(df.groupby(["cell", "controller"])[["delivered", "robots_lost"]].median())


if __name__ == "__main__":
    main()
```

```python
"""How well the swarm's repellent map picks out the true hazard (spec section 4).

ROC AUC = probability that a randomly chosen hazard cell carries more
repellent than a randomly chosen safe cell (ties count half). 0.5 means the
map carries no information; 1.0 means it separates hazard from safe perfectly.
"""

from __future__ import annotations

import numpy as np
from scipy.stats import rankdata

from swarmhazard.pheromone import RepellentField
from swarmhazard.world import World, in_hazard


def hazard_mask(world: World, field: RepellentField) -> np.ndarray:
    gx, gy = np.meshgrid(field.centres, field.centres, indexing="ij")
    pts = np.column_stack((gx.ravel(), gy.ravel()))
    return in_hazard(world, pts).reshape(field.n, field.n)


def field_auc(grid: np.ndarray, mask: np.ndarray) -> float:
    pos = grid[mask]
    neg = grid[~mask]
    if len(pos) == 0 or len(neg) == 0:
        return float("nan")
    ranks = rankdata(np.concatenate((pos, neg)))
    u = ranks[: len(pos)].sum() - len(pos) * (len(pos) + 1) / 2
    return float(u / (len(pos) * len(neg)))
```

```python
"""The parameter-selection rule, fixed in docs/hypotheses.md before tuning ran.

Highest median items delivered; ties broken by the lowest mean robots lost.
"""

from __future__ import annotations

import pandas as pd


def select_best(df: pd.DataFrame, params: list[str], controller: str) -> dict[str, float]:
    cols = [f"p_{p}" for p in params]
    summary = (df[df["controller"] == controller]
               .groupby(cols)
               .agg(delivered=("delivered", "median"), lost=("robots_lost", "mean"))
               .reset_index()
               .sort_values(["delivered", "lost"], ascending=[False, True]))
    best = summary.iloc[0]
    return {p: float(best[f"p_{p}"]) for p in params}
```

```python
"""Pick the best tuning cell and merge its parameters into configs/tuned_params.yaml.

Rule (docs/hypotheses.md): highest median items delivered; ties -> lowest mean robots lost.

Usage:
    python scripts/select_params.py results/tune_c2.csv C2 repel_weight deposit_sigma decay
"""

from __future__ import annotations

import sys
from pathlib import Path

import pandas as pd
import yaml

from swarmhazard.tuning import select_best

ROOT = Path(__file__).resolve().parents[1]
OUT = ROOT / "configs" / "tuned_params.yaml"


def main(csv: str, controller: str, *params: str) -> None:
    df = pd.read_csv(csv)
    cols = [f"p_{p}" for p in params]
    table = (df[df["controller"] == controller].groupby(cols)
             .agg(delivered=("delivered", "median"), lost=("robots_lost", "mean"), runs=("seed", "size"))
             .sort_values(["delivered", "lost"], ascending=[False, True]))
    print(table.head(10).to_string())

    best = select_best(df, list(params), controller)
    current = yaml.safe_load(OUT.read_text()) if OUT.exists() else {}
    current = current or {}
    current.update(best)
    header = (f"# Tuned parameters (spec section 3). Written by scripts/select_params.py.\n"
              f"# Last update: {controller} from {Path(csv).name}, code {df['git_commit'].iloc[0]}.\n"
              f"# Rule: highest median items delivered; ties -> lowest mean robots lost.\n")
    OUT.write_text(header + yaml.safe_dump(current, sort_keys=True))
    print(f"\nchosen: {best} -> {OUT}")


if __name__ == "__main__":
    main(*sys.argv[1:])
```

````markdown
# Pre-registered hypotheses and analysis plan

Committed before any main experiment (E1–E7) runs. Changing anything here after
main results exist must be reported in the paper as a deviation.

## Primary metric

Items delivered to the nest per run (10,000 steps, ~17 simulated minutes).
Secondary: robots lost; items per robot lost; localisation AUC (marking controllers).

## Hypotheses (spec section 4)

| ID | Claim | Experiment | Test |
|---|---|---|---|
| H1 | C2 delivers more items than C0 | E1 | one-sided Mann–Whitney U, A12 > 0.5 |
| H2 | C2 loses fewer robots than C1 | E1 | one-sided Mann–Whitney U on robots lost |
| H3 | In the random-failure control, C2's item cost relative to C0 is small: \|A12 − 0.5\| < 0.14 | E2 (no-hazard level) | A12 with bootstrap 95% CI; supported if the whole CI lies inside 0.36–0.64 |
| H4 | C3 delivers more items than C2 when the hazard is next to a patch | E1 | one-sided Mann–Whitney U |

## Statistics

- 100 seeds per cell. α = 0.05; within each experiment, Holm correction across the pairwise comparisons.
- Report medians with bootstrap 95% CIs (10,000 resamples) and Vargha–Delaney A12 with bootstrap 95% CIs.
- Per experiment: Kruskal–Wallis across controllers, then pairwise Mann–Whitney U against C2.
- `first_loss_step = -1` means no robot was lost; treat it as missing, never as a number.

## Tuning protocol (spec section 3)

- Tuned at the baseline configuration only, on experiments `tune_c2` and `tune_c3`, whose
  random streams are independent of the gate and of E1–E7.
- C2 grid: repel_weight {0.5, 1, 2, 4} × deposit_sigma {0.2, 0.3, 0.5} × decay {0.0002, 0.0005, 0.002}; 20 seeds per cell.
- C3 grid: risk_k {0.25, 0.5, 1, 2, 4} on top of the chosen C2 values; 20 seeds per cell.
- Selection rule: highest median items delivered; ties → lowest mean robots lost.
- Fixed, not tuned: deposit_amount = 1 (redundant with repel_weight), wreck_weight = 1 (shared with C1).
- The chosen values are committed to `configs/tuned_params.yaml` before any main experiment runs.

## Reproducibility claim

Exact re-runs are claimed on the same machine and software environment (recorded per row).
Across machines, results are expected to agree statistically, not bit for bit.
````

````markdown
   the same amount every step. Comparisons between controllers are now paired
   for the whole run, which makes differences easier to detect.
2. **A fair oracle.** The week-1 oracle kept 0.5 m clear of the hazard and so
   skipped part of a nearby item patch, which meant it was not really "the best
   possible". It now only refuses to step inside, and slides along the hazard
   edge when blocked.
3. **Item bookkeeping.** We now count every pickup and check it ends up
   delivered, lost with a robot, or still being carried.
4. **Provenance.** Every result row records the code version, the machine and
   every package version, and the runner refuses to run on uncommitted code.
5. **Two new controllers.** C1 only steers around wrecks it can see (no
   memory). C3 marks like C2 but pushes less when items are in view.
6. **Localisation AUC.** A score from 0.5 (the repellent map says nothing) to
   1.0 (it outlines the hazard perfectly).
````
